# Configurations

This directory contains flat Hydra configurations for candidate models,
materialization providers, and evaluator services.

User-facing setup and selection are documented in
[Using doteBench](../docs/usage.md), [Candidate integrations](../README.md#candidate-integrations),
[Data materialization](../docs/materialization.md), and
[Evaluation protocol](../docs/evaluation.md). Configuration ownership and
extension rules are documented in the
[Development guide](../docs/development.md).
